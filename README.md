## Démo interactive d'homemadeSUTOM

Cette petite démo jouable permet de présenter mon deuxième projet personnel, homemadeSUTOM, dans mon portfolio.

## Quelques explications

homemadeSUTOM reprenait le concept du site SUTOM, créé par Jonathan Magano.
Le but fonctionnel de cette application était donc de reprendre le même concept, tout en proposant un mode "entraînement", c'est à dire la
possibilité de pratiquer le SUTOM à l'infini, ainsi qu'un mode "contre-la-montre", dans lequel le joueur disposait de 10 minutes pour deviner un maximum de mots, chaque mot rapportant 10 points, les totaux des points donnant lieu ensuite à un classement des utilisateurs inscrits.
L'autre but essentiel de cette application était de  pratiquer le développement web dans un but d'apprentissage, et c'est notamment pour cette raison que je n'ai jamais utilisé le code du SUTOM original, disponible en open-source.

Une première version 1.0 avait été uploadée et configurée sur un vps.
J'ai ensuite commencé une formation officielle de développeur web chez OpenClassrooms et, par manque de temps, homemadeSUTOM a été totalement délaissé.

J'ai choisi de mettre ce projet en avant dans mon portfolio car il m'a permis de me familiariser avec un framework node.js qui me plaît beaucoup : Adonis JS.

## Spécifications techniques

homemadeSUTOM utilisait Adonis JS 6 en back-end, le moteur de template EdgeJS, du HTML/CSS + JavaScript Vanilla pour le front-end.
Je compte désormais faire une refonte du site, avec Adonis JS 7 en back-end, et Inertia.js + React pour le front.

En revanche, cette démo interactive n'ayant que pour but de présenter rapidement le projet dans mon portfolio, elle utilisera simplement du HTML, CSS et du Javascript Vanilla, sans aucune technologie back-end.
